# News Explorer Frontend

## Project Description

News Explorer is a responsive web application that allows users to search for news articles and save their favorite articles to a personal account.

Users can register, log in, search for news by keyword, and manage saved articles. The application uses authentication and protected routes to ensure that saved articles are only accessible to logged-in users.

This project demonstrates frontend routing, API integration, authentication, and responsive UI development.

## Running the Project Locally

Clone the repository:

```bash
git clone https://github.com/Briebestcode30/news-explorer-frontend.git
```

Navigate into the project directory:

```bash
cd news-explorer-frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the project:

```bash
npm run build
```

Deploy to GitHub Pages:

```bash
npm run deploy
```
